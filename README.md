# 喵来提醒

一个 Windows 桌面待办提醒小工具：设好时间和备注，到点弹出置顶窗口提醒你。支持每天 / 每周 / 每月 / 每年循环，支持托盘常驻、开机自启和桌面悬浮窗。

基于 Python + PyQt5 开发，用 PyInstaller 打包为单文件 `喵来提醒.exe`，免安装、双击即用。

## 主要功能

- **到点弹窗**：提醒窗口强制置顶，同时把主窗口收起，不会被其他窗口盖住
- **循环提醒**：不重复 / 每天 / 每周 / 每月 / 每年；每月和每年还能指定「第一天 / 最后一天」
- **稍后提醒**：弹窗上的「稍后提醒(N分钟)」临时顺延，不改变原任务；N 可自己设（1–1440 分钟）
- **托盘常驻**：点 × 只是收起，程序继续在后台跑；托盘图标双击恢复窗口
- **桌面悬浮窗**：一个半透明小窗，置顶显示所有待办和剩余时间，可拖动
- **开机自启**：写注册表 `HKCU\...\Run`，开机后静默启动并行到托盘
- **过期汇总**：关机期间多次到期的循环任务，开机合并成一张清单弹出，不会一次弹几十个窗
- **单实例保护**：重复双击不会再开第二个进程，只会提示「已经在运行中」

## 快速开始

1. 双击 `喵来提醒.exe`
2. 在「待办时间」里选好日期时间，或点「获取当前时间」后手动往后调
3. 在「待办备注」里写事项，比如「下班打卡」
4. 按需要选「重复类型」，点「添加」
5. 到点就会弹出提醒，点「知道啦」结束

详细的操作说明见 [操作说明.md](操作说明.md)。

## 界面速查

| 区域 | 说明 |
|---|---|
| 待办时间 | 格式固定为 `yyyy年MM月dd日HH时mm分`，可直接改任意一段 |
| 获取当前时间 | 把时间框重置为此刻，常用于「从当前时间往后调几分钟」 |
| 显示悬浮窗 | 打开 / 关闭桌面悬浮窗 |
| 待办备注 | 提醒内容，不能为空 |
| 重复类型 | 不重复 / 每天 / 每周 / 每月 / 每年 |
| 日期选项 | 「第一天 / 最后一天」，**只有选每月或每年时才可点** |
| 添加 | 添加待办（时间早于现在会被拒绝） |
| 待处理 / 已完成 / 全部事项 | 三个标签页，按状态筛选 |
| 勾选框 | 勾上即标记完成，任务会移到「已完成」 |
| 右键待办 | 编辑 / 删除 |

菜单栏「设置」里可以开关**开机自启动**、调整**默认稍后提醒时间**（默认 5 分钟）。这两项在托盘右键菜单里也有入口。

## 循环规则

| 类型 | 下次提醒时间 |
|---|---|
| 每天 | 原时间的次日同一时刻 |
| 每周 | 原时间的下周同一星期几、同一时刻 |
| 每月（默认） | 下个月的同一天同一时刻；该月没有这一天时自动落到月末（如 1月31日 → 2月28/29日） |
| 每月（第一天） | 下个月 1 号，时分沿用原时间 |
| 每月（最后一天） | 下个月最后一天，时分沿用原时间 |
| 每年（默认） | 明年同月同日同时刻 |
| 每年（第一天） | 明年 1 月 1 日 |
| 每年（最后一天） | 明年 12 月 31 日 |

循环任务点「知道啦」不会变成"已完成"，而是把时间推进到下一次，所以它会一直留在「待处理」里。

## 数据存放

任务全部存在 `tasks.json`，**和 `喵来提醒.exe` 放在同一个文件夹**：

```json
[
  {
    "datetime": "2026年11月14日18时00分",
    "note": "下班打卡",
    "completed": false,
    "cycle_type": "daily",
    "day_type": null
  }
]
```

字段说明：

| 字段 | 取值 |
|---|---|
| `datetime` | `yyyy年MM月dd日HH时mm分` |
| `note` | 提醒内容 |
| `completed` | `true` / `false` |
| `cycle_type` | `none` / `daily` / `weekly` / `monthly` / `yearly` |
| `day_type` | `null` / `first` / `last`（只有 monthly、yearly 用得上） |

**备份就是复制这个文件**。想迁移到另一台电脑，把 exe 和 tasks.json 一起拷过去即可。

仓库里附了一份 [tasks.example.json](tasks.example.json) 供参考格式，它只有两条示例数据，不含任何真实内容。

> 注意：exe 每次启动都会读 exe 同级的 tasks.json。如果把程序放到 `C:\Program Files` 这类需要管理员权限的目录，写入可能失败导致新任务保存不了，建议放在自己的文档目录或 D 盘。

## 从源码运行

需要 Python 3.8+ 和 PyQt5：

```bash
pip install PyQt5
python reminder_app.py
```

## 自己打包

双击 `package.bat`，或者在项目目录执行：

```bash
pyinstaller --onefile --windowed --noconsole --name "喵来提醒" --icon=application-note.ico reminder_app.py
```

产物在 `dist/喵来提醒.exe`，约 36MB。

## 常见问题

**双击没反应？**
程序可能已经在后台运行了（会弹「已经在运行中」）。看右下角托盘区，双击图标即可。

**点 × 关不掉？**
这是设计如此：点 × 只是收起窗口，程序继续在后台等待提醒。真要退出，用托盘右键菜单里的「退出」。

**提醒没弹出来？**
确认程序还在托盘区。如果开机自启已开启但没生效，检查任务管理器 → 启动项里是否被系统禁用了。

**换电脑后任务不见了？**
tasks.json 没跟着走。把旧电脑上的 tasks.json 拷到新电脑 exe 同级目录。

**会不会上传我的数据？**
不会。程序只读写本地 tasks.json，没有任何联网行为。仓库里也不包含任何真实任务数据。
